# Forgio — Frontend

React Native + Expo + TypeScript mobile app for the Forgio manufacturing management system.

## Setup

```bash
npm install
npx expo start
```

## Folder Structure

- `src/app/(auth)` — Login and Register screens
- `src/app/(manager)` — All manager screens
- `src/app/(worker)` — All worker screens
- `src/app/(driver)` — Driver screens
- `src/components` — Reusable UI components
- `src/services` — API call functions (connects to backend)
- `src/types` — TypeScript type definitions
- `src/constants` — Colors and config

## Team

Each frontend dev picks screens to build. All API calls go in `src/services`.
